| | |
|---|---|
| **Lý thuyết** | Ngắn gọn, có điểm chính tóm tắt cuối bài |
| **Code Lab** | Code mẫu tô màu, bấm **Chạy Code** là chạy thật: Python, SQL (PostgreSQL) và Lua chạy ngay trong trình duyệt; C++, Java, Go, Rust, C#, Kotlin, Swift, PHP, Ruby… biên dịch trên máy chủ |
| **Trắc nghiệm** | Câu hỏi do AI sinh theo đúng nội dung bài |
| **Bài tập** | Viết code và nhận chấm điểm, nhận xét từ AI |
| **Gia sư AI** | Hỏi bất cứ lúc nào, trả lời đúng ngôn ngữ bạn đang dùng |

## Thực hành như làm thật

- **Live IDE**: sửa HTML, CSS, JS và xem trang thay đổi ngay; chế độ Thiết kế cho phép chỉnh giao diện bằng AI.
- **Terminal Linux mô phỏng**: gõ lệnh thật, có hệ thống tệp riêng, chạy ngay trong trình duyệt.
- **Phòng lab Nginx**: cấu hình máy chủ web theo từng nhiệm vụ.
- **Thử thách CTF**: AI ra đề từ chính dữ liệu trong máy, dùng lệnh Linux để săn cờ `FLAG{...}` và tích điểm XP.

## Từ học sang đi làm

- **Project Lab**: AI gợi ý ý tưởng dự án theo cấp độ hoặc chủ đề bạn muốn, có mentor chat đi kèm; nộp code để được chấm theo 4 tiêu chí.
- **Cố vấn việc làm**: tư vấn định hướng dựa trên chính tiến độ học của bạn, đọc được cả link tin tuyển dụng bạn dán vào.
- **Tìm việc**: gom tin từ VietnamWorks, RemoteOK, Arbeitnow, Remotive và WeWorkRemotely, kèm tỉ lệ phù hợp với hồ sơ của bạn.
